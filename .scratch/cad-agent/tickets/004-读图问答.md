# 嵌入 Pi Agent 实现读图问答

**Blocked by**: 002, 003

## 目标
右侧对话面板接入嵌入式 Pi Agent，主 Agent 通过读图工具访问当前图纸的结构化结果，回答用户关于图纸的问题，并流式展示。

## 涉及层
- [x] 数据层：读图工具输入/输出契约（摘要、图层、实体查询）
- [x] 逻辑层：pi-agent-core 会话、系统提示、工具注册、取消与超时
- [x] UI层：聊天面板、流式输出、停止按钮、工具调用调试视图
- [x] 测试：假模型工具调用测试、真实模型手工用例
  - 假模型用例已覆盖（摘要/图层/文字/中断/未开图）；真实模型手工用例需用户配置 API Key 后执行。

## 验收标准
- 能正确回答图层数量、实体统计、指定图层内容、文字内容等事实问题
- 工具调用过程可在调试视图查看
- 信息不足时明确说明，不编造图纸内容
- 用户可中断正在进行的回答
