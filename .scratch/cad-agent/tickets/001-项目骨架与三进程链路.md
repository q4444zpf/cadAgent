# 项目骨架与三进程链路

**Blocked by**: 无

## 目标
启动 Electron 应用后，主进程拉起 Node Agent 运行时与 Python sidecar，界面能看到 sidecar 就绪状态与 ezdxf 版本，证明三层通路可工作。

## 涉及层
- [x] 数据层：Node ↔ Python 的 JSON 协议定义与 schema
- [x] 逻辑层：Electron 主进程、sidecar 生命周期管理、Python 服务入口
- [x] UI层：应用窗口与 sidecar 状态栏
- [x] 测试：协议契约测试、启动 smoke 测试

## 验收标准
- `npm run dev` 能打开窗口，状态栏显示 sidecar 就绪与 ezdxf 版本
- 协议请求/响应通过 JSON Schema 校验
- 手动结束 sidecar 进程后状态变为异常，并可手动重启
- 一条命令可运行契约测试与启动 smoke 测试

## 实现备注
- 协议：`src/shared/protocol.ts` 的 zod schema 校验请求/响应；`tests/contract/sidecar.contract.test.ts` 覆盖健康检查、异常退出与重启。
- 生命周期：`src/node/sidecar/client.ts` 负责启动、请求超时、进程退出检测与重启；主进程广播状态，界面状态栏显示 ezdxf/Python 版本并可重启。
- 验证：`npm run test:contract`、`npm run test:smoke`（覆盖启动与状态栏）。
