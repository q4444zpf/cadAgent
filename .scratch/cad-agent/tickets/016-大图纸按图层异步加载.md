# 大图纸按图层异步加载

**Blocked by**: 无（基于已完成的 014/015 摘要模式）

## 目标
打开超过 50 MB 的图纸时先显示摘要与可交互图层清单，随后按图层实体数从小到大的顺序异步取几何并渐进渲染；全部图层加载完成后可继续缩放、平移与图层显隐。

## 涉及层
- [x] 数据层：sidecar 保留已解析 ezdxf 文档；`open_dxf` / `layer_entities` / `close_dxf`
- [x] 逻辑层：Node 客户端长超时请求、IPC 校验当前图纸、切换图纸释放文档缓存
- [x] UI层：摘要先行、加载进度、渐进渲染、完成提示、缩放平移不因新图层到达而重置
- [x] 测试：Python 文档缓存与分层切片、契约测试、图层排序单测、52 MB oversize smoke、85 MB 实图验证

## 验收标准
- 大图纸打开后先出现「大图纸摘要模式」与图层清单，不等待几何
- 图层按实体数升序加载（0 实体图层跳过），界面显示「正在加载图层 x/N」与进度
- 每完成一层，其几何立即出现在画布；加载过程中缩放、平移不因新图层到达而重置
- 全部图层加载完成后显示完成状态，缩放、平移、图层显隐可用
- 切换图纸后旧图层请求不会污染新图；sidecar 只保留当前图纸文档
- 未知图层返回空实体，不崩溃
