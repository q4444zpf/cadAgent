# DXF 导入、解析、预览与图层控制

**Blocked by**: 001

## 目标
用户选择 DXF 文件后，应用完成解析并在预览区渲染，同时展示图层清单；支持缩放、平移与图层显隐。

## 涉及层
- [x] 数据层：解析结果结构（图层、实体、句柄、包围盒、文字、标注、块展开）
- [x] 逻辑层：导入流程、ezdxf 解析、错误处理、DWG 提示
- [x] UI层：文件选择、画布预览、图层面板、缩放平移
- [x] 测试：fixture DXF 解析断言、导入 E2E、损坏文件分支

## 验收标准
- 简单图、含块图、含标注图三类 fixture 均能正确渲染
- 实体计数与图层清单与 ezdxf 直接解析一致
- 图层显隐实时生效，预览与控制一致
- 损坏或不支持的 DXF 给出可读错误且应用不崩溃
- 选择 DWG 时提示需经 ODA File Converter 转换
