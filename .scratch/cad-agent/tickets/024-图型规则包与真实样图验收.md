# 图型规则包与真实样图验收

**Blocked by**: 010、023

## 目标
010 确定首批图型后，以书面确认的图层/线型约定与校验规则集启用领域校验；用真实样图生成的文件可由 CAD 软件打开，预览与文件一致，并通过人工验收。

## 涉及层
- [ ] 数据层：每种图型的规则集（`requiredLayers` / `requiredClosedLayers` / `requireDimensions` / `allowedTypes` / `minEntities`）；必要的图层与线型约定配置
- [ ] 逻辑层：按图型选择规则集传入 `validate_dxf`；提示词补充该图型的语义绘图约定（仍不引入模板注册表，遵守 ADR-0003）
- [ ] UI层：结果面板显示图型名称与所用规则集；校验问题可定位到句柄/图层
- [ ] 测试：每种图型规则集的正/负样例；真实 DWG/DXF 样图的生成 smoke；CAD 软件人工打开验收记录

## 验收标准
- 首批图型与规则集由 010 书面确认，图层命名与线型符合图型约定
- 真实样图生成的 DXF 能被 AutoCAD 或等效软件正常打开，预览与文件内容一致
- 关键尺寸与标注完整，关键几何闭合性通过校验；失败问题带句柄/图层定位
- 生成过程不修改任何原始图纸，人工验收记录与截图归档
- 本 ticket 完成即补齐原 011/012 中依赖 010 的部分
