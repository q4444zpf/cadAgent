# 知识库管理面板与文档入库

**Blocked by**: 001, 002

## 目标
应用内知识库页面支持导入 PDF、Word、DXF 与结构化参数表，完成解析、切分、embedding 与本地混合索引，并显示每个文件的状态。

## 涉及层
- [x] 数据层：本地索引结构（向量 + 全文）、文档元数据与 chunk 来源
- [x] 逻辑层：解析器、切分、embedding 调用、混合检索、删除与重建
- [x] UI层：知识库管理页、导入、状态与失败原因、重建进度
- [x] 测试：固定文档集召回、出处正确性、删除/重建一致性

## 验收标准
- 四类来源均可成功入库，失败项显示原因并可重试
- 基准问题能召回预期片段，结果带文件名与页码或实体句柄
- 删除文档后不再被检索，重建后索引条数与内容一致
- 索引状态在界面可见，无需查看日志

## 实现备注
- 索引：`python/cad_service/kb.py`，JSON 索引落盘（index.json），哈希 embedding + 关键词混合打分（0.6/0.4，阈值 0.15），无需外部 API。
- 出处定位：PDF 页码、Word 段落、DXF 文字句柄、CSV 行号。
- 验证：`python/tests/test_kb.py` 6 项 + `test_protocol.py` KB 往返；`scripts/smoke-kb.mjs`（`test:smoke:kb`）覆盖导入/失败/重试按钮/检索出处/删除/重建一致性，截图 `out/smoke-kb.png`。
- 失败重试成功路径由 Python 测试覆盖（替换损坏文件后重新导入），E2E 仅验证失败原因与重试入口。
