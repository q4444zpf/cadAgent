# 语义化绘图工具全集

**Blocked by**: 018

## 目标
模型可用完整的语义化 CAD 工具绘制一个中性的矩形沟槽断面示意（图层、闭合多段线、文字、线性标注，必要时圆/弧），保存文件回读后的实体类型、数量与图层全部正确。

## 涉及层
- [ ] 数据层：sidecar `add_layer` / `draw_polyline` / `draw_circle` / `draw_arc` / `add_text` / `add_linear_dimension` / `drawing_info`
- [ ] 逻辑层：图层名合法性（非空、≤255、不含 `< > / \ " : ; ? * | =`）、ACI 1–255；多段线至少 2 点、闭合用 LWPOLYLINE `closed`；半径与字高必须为正、角度有限；文字非空；标注角度 0/90；`drawing_info` 返回实体数、各图层实体数与包围盒
- [ ] UI层：无新增界面；生成文件在既有结果面板中展示路径
- [ ] 测试：pytest 每个操作的有效/无效输入；契约测试 `add_layer → draw_* → add_text → add_dimension → generate → parse` 往返；GenerationAgent 单测覆盖各工具成功与失败返回；smoke 断言生成文件包含实际使用的实体类型与图层

## 验收标准
- 新文档自动包含图层 `0`；重复 `add_layer` 返回 `created: false`；同名但参数冲突报错
- 单点多段线被拒绝；`closed: true` 生成闭合 LWPOLYLINE；半径 ≤ 0、非有限角度、空文字分别被拒绝且错误信息可读
- `add_linear_dimension` 使用默认标注样式并完成渲染，回读为 DIMENSION 实体
- `drawing_info` 在保存前可用，实体数、图层统计与包围盒与实际一致
- 生成文件回读后的实体类型集合、数量与图层名和工具调用一致
- 假模型脚本绘制中性的矩形沟槽断面示意作为夹具，**不写入任何真实图型模板或领域规则**
