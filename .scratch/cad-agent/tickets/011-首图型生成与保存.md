# 首个图型的 CAD 工具集、生成与保存

**Blocked by**: 003, 009, 010

**状态**: 通用部分已由 018–022 取代（写图会话、语义工具、生成编排、校验、预览）；依赖 010 的图型规范与真实样图验收见 024。本 ticket 保留作历史记录，不再单独实施。

## 目标
为已确认的首批图型实现语义化 CAD 工具集，参数确认后由 Agent 调用工具生成新 DXF 并保存，同时在应用中预览。

## 涉及层
- [ ] 数据层：绘图工具参数 schema、生成文件元数据
- [ ] 逻辑层：Python 绘图工具（图层、线、多段线、标注、文字等必要子集）、Agent 工具包装、文件保存
- [ ] UI层：生成进度、保存位置、预览
- [ ] 测试：工具单测、生成文件回读、生成链路 E2E

## 验收标准
- 生成的 DXF 能被 AutoCAD 或等效软件正常打开
- 预览与保存文件内容一致
- 图层命名与线型符合该图型约定
- 整个生成过程不修改任何原始图纸
- 在设定超时内完成，无人工干预
