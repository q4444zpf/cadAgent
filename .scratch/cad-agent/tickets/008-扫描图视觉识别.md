# 扫描图视觉识别入库

**Blocked by**: 002, 006

## 目标
导入 PNG/JPG 扫描图纸后，经视觉模型生成文字描述与结构化要点，作为带来源标识的 chunk 进入知识库，可被检索。

## 涉及层
- [x] 数据层：图片存储、识别结果字段（描述、要点、置信、来源类型）
- [x] 逻辑层：视觉模型调用、失败重试、低置信处理
- [x] UI层：导入状态、来源标识与低置信提示
- [x] 测试：桩响应下的识别管线测试、失败分支

## 验收标准
- 扫描样图入库后可被基准问题检索命中
- 检索结果明确标注来源为“视觉识别”
- 低置信内容在结果中提示，不得作为唯一依据
- 视觉调用失败时可重试并显示原因

## 实现备注
- 视觉识别：`src/node/kb/vision.ts` 校验 PNG/JPG 签名后经 `ModelRuntime.complete`（vision 车道）调用多模态模型，要求 JSON 结果；假模型回复固定 `confidence: 0.55` 用于离线验证低置信路径。
- 入库：`python/cad_service/kb.py` 图片经 `_segments_image` 生成「概述」与「要点 N」chunk（region 定位），图片复制到 `<kbRoot>/assets/<docId><suffix>`；`import_document` 接受 `recognition/doc_id/name`，重建索引复用既有 id/name 与识别结果，避免改名导致来源丢失。
- 低置信：`LOW_CONFIDENCE = 0.6`（`src/shared/protocol.ts`），知识库列表与检索命中展示「视觉识别 / 低置信」标签及“不能作为唯一依据”提示；`KbAgent` 在全为低置信命中时追加人工核对提醒。
- 失败分支：无效签名返回「图片文件已损坏或不是有效的 PNG/JPG」，模块级失败写入文档错误供 UI 重试；smoke 覆盖 `broken.pdf` 与 `scan-broken.png` 两类失败及重试按钮。
- 验证：pytest 18、vitest 61（含 `vision.test.ts` 6 项与低置信问答）、`npm run test:smoke:kb` 通过，截图 `out/smoke-kb.png` 展示扫描图入库、低置信命中与失败原因。
