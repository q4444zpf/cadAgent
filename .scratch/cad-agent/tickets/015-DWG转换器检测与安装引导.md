# DWG 转换器检测与安装引导

**Blocked by**: 无

## 目标
应用启动时检测本机 ODA File Converter；缺失时明确提示「必须安装」，并引导用户完成下载、安装、重新检测；打开 DWG 被拒时可直接跳到安装指引。安装器不内置转换器（受 ODA 许可限制，不可再分发）。

## 涉及层
- [x] 数据层：扫描 `%ProgramFiles%` / `%ProgramFiles(x86)%` 下的 `ODA\ODAFileConverter <版本>`，取最高版本；支持 `ODA_FILE_CONVERTER` 环境变量覆盖
- [x] 逻辑层：`converter:status`、`converter:open-download` IPC，预加载与类型声明
- [x] UI层：顶部提示条（查看安装指引 / 暂时忽略）、设置页「DWG 转换器」三步指引 + 重新检测、DWG 错误框跳转指引
- [x] 测试：检测单元测试；E2E smoke 以 `SMOKE_ODA_MISSING=1` 模拟未安装

## 验收标准
- 未安装时应用顶部出现「未检测到 ODA File Converter」提示条
- 提示条可进入设置查看三步指引，并能打开 ODA 官网下载页
- 设置页显示检测状态与路径；点击「重新检测」即时刷新
- 安装完成后重新检测成功，提示条在本会话内随之消失
- 提示条可「暂时忽略」；未安装不影响 DXF 图纸的读图与生成
- 单元测试覆盖版本选择、自定义路径优先、目录无 exe 时忽略、未安装返回空

- 界面：`App.tsx` 提示条、`SettingsView.tsx` 转换器面板；样式 `.converter-banner` / `.converter__steps`
