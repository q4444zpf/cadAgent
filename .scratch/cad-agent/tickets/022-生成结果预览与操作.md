# 生成结果预览与操作

**Blocked by**: 021

## 目标
生成成功后结果面板展示独立预览；用户可「设为当前图纸」或「在文件夹中显示」，生成完成不会自动替换当前读图状态。

## 涉及层
- [ ] 数据层：`GenerationOutcome.preview?: Drawing`，复用 `sidecar.parseDrawing` 回读生成文件
- [ ] 逻辑层：主进程回读预览，回读失败时省略 `preview` 并在结果中说明；「在文件夹中显示」使用 `shell.showItemInFolder` 并校验路径存在
- [ ] UI层：`src/renderer/src/design/GeneratedPreview.tsx` 复用 `DrawingCanvas` 展示生成文件；显示保存路径、实体/图层统计、校验状态；「设为当前图纸」「在文件夹中显示」按钮；预览不可用时的降级文案
- [ ] 测试：主进程单测（预览成功、回读失败省略 preview）；smoke 断言预览画布有墨迹、截图、「设为当前图纸」后图纸视图切换且图层列表更新

## 验收标准
- 生成成功后结果面板显示独立预览与保存路径，预览内容与文件一致
- 预览回读失败不影响生成记录与文件，界面提示「预览不可用」
- 点击「设为当前图纸」后图纸视图与图层列表切换到生成文件；未点击时当前读图状态保持不变
- 「在文件夹中显示」打开文件所在目录；文件已被移动时给出错误提示而非崩溃
- 生成完成不会自动替换或关闭当前图纸
