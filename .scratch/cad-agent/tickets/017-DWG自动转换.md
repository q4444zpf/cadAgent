# DWG 自动转换

**Blocked by**: 无（基于已完成的 014/015 检测与引导、016 摘要加载）

## 目标
本机安装 ODA File Converter 后，打开 DWG 无需手动另存为 DXF：应用自动调用转换器生成 DXF，并按文件名与修改时间缓存，随后走既有解析、摘要与渐进加载链路。

## 涉及层
- [x] 数据层：`src/node/dwg/convert.ts`（参数构造、缓存键、临时目录、超时与失败信息）
- [x] 逻辑层：`loadDrawing` 对 `.dwg` 检测转换器 → 自动转换 → 以缓存 DXF 解析；转换进度事件 `drawing:phase`
- [x] UI层：打开中显示「正在转换 DWG…」；未安装转换器时给出安装指引；错误区分转换失败
- [x] 测试：转换模块 9 个单测（参数、缓存命中、失败、超时、真实子进程）；real-DWG smoke；全量回归

## 验收标准
- 已安装 ODA File Converter 时，导入 DWG 自动转换并以 DXF 解析，不再提示手动另存
- 转换缓存位于用户数据目录 `dwg-cache/<sha1>.dxf`，键为「路径 + 大小 + 修改时间」；未修改的文件再次打开命中缓存（毫秒级）
- 转换期间界面显示进度提示，转换完成后文件名仍显示原 DWG 名
- 转换器缺失时返回「DWG 需先转换」，界面提供设置页安装指引
- 转换失败或超时（默认 300 秒）给出明确错误，不留下半成品缓存
- 实测 13 MB DWG→88 MB DXF 转换约 8 秒，随后按摘要模式打开 26 个图层、143,788 实体，23/23 非空图层加载完成
