# 写图会话与最小生成闭环

**Blocked by**: 无（复用 001 三进程链路与 009 参数确认状态机）

## 目标
参数确认后出现「生成图纸」入口；假模型通过语义工具创建一张仅含一条直线的 R2018 DXF，保存到生成目录，界面显示保存路径，历史页出现一条「未校验」生成记录。

## 涉及层
- [ ] 数据层：`GenerationRequest` / `GenerationOutcome` 协议；sidecar `create_dxf` / `draw_line` / `generate_dxf` / `discard_dxf`；`SMOKE_GENERATED_DIR` 覆盖生成目录
- [ ] 逻辑层：`python/cad_service/writing.py` 单活动文档会话（`docId`、新建时丢弃旧文档）；坐标有限数、图层名规则、`.dxf` 扩展名、空图与已存在目标拒绝；`SidecarClient` 写操作 15 秒 / 保存 60 秒超时；`src/node/design/generation-agent.ts` 最小工具 `create_drawing` / `draw_line` / `save_drawing`（路径与 `docId` 由主进程闭包注入）；主进程 `design:generate` 校验会话已确认、单任务锁、输出路径分配 `userData/generated/YYYYMMDD-HHmmss-<标题>.dxf`、调用 `historyStore.addGeneration`
- [ ] UI层：`DesignView` 在 `confirmed` 后显示「生成图纸」；生成中、失败、成功路径；历史视图显示「未校验」记录
- [ ] 测试：pytest 写图会话正负例；契约测试 `create → draw_line → generate → parse`；路径分配与门禁单测；GenerationAgent 单测；扩展 `runDesignSmoke` 覆盖确认→生成→文件存在→记录出现

## 验收标准
- 仅 `confirmed` 会话显示「生成图纸」；`draft` / `cancelled` 调用 `design:generate` 返回「参数清单未确认」
- 生成进行中再次调用返回「已有生成任务进行中」，不会启动第二个任务
- 生成文件为 R2018（AC1032）、单位 mm，回读后模型空间含 1 条 LINE，图层与端点与工具调用一致
- 模型的 `save_drawing` / `validate_drawing` 工具 schema 不含路径参数；未 `create_drawing` 就绘图或保存返回「请先创建图纸」
- 目标文件存在且非本会话重试时拒绝覆盖；首次分配的文件必定不存在
- 生成记录写入当前会话并在历史页显示（`validation: null` 显示「未校验」）
- 生成过程不修改任何已有图纸文件，测试断言原图纸路径与内容不变
