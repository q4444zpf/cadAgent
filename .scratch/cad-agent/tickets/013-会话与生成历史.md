# 会话与生成历史持久化

**Blocked by**: 005, 007, 012

## 目标
本地持久化会话列表、历史消息与生成记录（参数、校验结果、文件路径），应用重启后可恢复。

## 涉及层
- [x] 数据层：本地 SQLite schema（会话、消息、生成记录、当前图纸关联）
- [x] 逻辑层：读写与迁移、失效文件处理
- [x] UI层：历史会话列表、生成记录查看
- [x] 测试：重启恢复 E2E、失效路径分支

## 验收标准
- 重启应用后可恢复历史会话及其基本上下文
- 生成记录可回看参数、校验结果与文件路径
- 文件被移动或删除时给出提示且不影响其他记录
- 删除会话不会删除已生成的 DXF 文件

## 实现备注
- 存储：`src/node/history/store.ts` 使用 `node:sqlite`（Electron 45 内置，无原生依赖），`PRAGMA user_version = 2` 迁移建 sessions / messages / generations / meta 四表，级联删除消息与生成记录；`meta.last_session` 记录上次会话。
- 逻辑：`src/main/index.ts` 在问答时自动建会话并持久化用户/助手消息（含出处与引用），打开图纸时更新会话关联图纸；`history:list/current/get/create/open/delete` IPC 提供完整读写；生成记录读取时用 `existsSync` 标记 `fileExists`，失效文件只提示不阻断。
- UI：`src/renderer/src/chat/ChatPanel.tsx` 启动即恢复当前会话消息，新增「新对话」；`src/renderer/src/history/HistoryView.tsx` 提供会话列表、消息回看、生成记录（参数/校验/文件路径/失效提示）、打开与删除（删除前确认并明示 DXF 文件保留）；`App.tsx` 新增「历史」导航。
- 测试：`tests/unit/history-store.test.ts` 5 例覆盖重开恢复、失效文件、级联删除保留 DXF、列表排序与计数、未知会话；`scripts/smoke-history.mjs` 两阶段（seed/restore）真实重启验证聊天恢复与删除，并通过 `--dxf` 断言会话关联图纸（simple.dxf）在重启后仍保留。
- 生成记录数据结构、IPC 与 UI 已就绪；实际记录待 011/012（首图型生成、校验重试）落地后写入 `historyStore.addGeneration`。
