# 生成需求、参数清单与参数确认

**Blocked by**: 004, 007

## 目标
用户用自然语言描述生成需求，主 Agent 结合知识库整理参数清单（名称、值、单位、依据、待确认项），在界面中可编辑，确认后才允许生成。

## 涉及层
- [x] 数据层：参数清单 schema、会话中的确认状态
- [x] 逻辑层：需求解析、参数整理、确认状态机、未确认拦截
- [x] UI层：参数表格、依据展示、编辑、确认/取消
- [x] 测试：假模型参数生成、未确认不触发生成、取消无副作用

## 验收标准
- 参数清单覆盖所选图型的关键参数，每条带依据或标为假设
- 用户可修改参数，修改值进入后续生成
- 未确认前不会产生任何 DXF 文件
- 取消后不留下半成品文件

## 实现备注
- 协议：`DesignParameter / ParameterList / DesignSessionView`（`src/shared/protocol.ts`），参数含名称、取值、单位、依据与假设标记；`DesignPropose/Confirm/Cancel` IPC 输入均经 zod 校验。
- 主 Agent：`src/node/design/agent.ts`，系统提示要求先 `ask_knowledge` 再经 `propose_parameters` 提交；`buildParameterList` 拒绝无依据且未标假设的参数；假模型按知识库命中生成 4 项参数（净宽/壁厚/纵坡/盖板），无命中时全部标为假设。
- 确认状态机：`src/node/design/session.ts`，draft → confirmed / cancelled；确认时应用用户编辑值并生成 `confirmedValues` 供后续生成读取；未知参数、空值、重复确认、取消后再确认均被拒绝。
- UI：新增「生成」视图 `DesignView.tsx`，参数表格可编辑取值、展示依据与「假设」标记，确认后锁定输入并提示待生成；取消提示未生成任何文件。
- 验证：`tests/unit/design-session.test.ts` 6 项、`tests/unit/design-agent.test.ts` 5 项；`npm run test:smoke:design` 覆盖知识库依据、假设标记、改值确认与取消，并在每个阶段断言生成目录无 DXF，截图 `out/smoke-design.png`。
