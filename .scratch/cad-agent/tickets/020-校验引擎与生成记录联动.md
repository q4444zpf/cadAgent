# 校验引擎与生成记录联动

**Blocked by**: 019

## 目标
保存后自动从磁盘回读并执行 `validate_dxf`，通过或不通过都在生成结果面板显示，校验报告写入生成记录；历史页显示「校验通过」或「校验未通过（N）」与问题清单。

## 涉及层
- [ ] 数据层：`rules` 参数（`requiredLayers` / `requiredClosedLayers` / `requireDimensions` / `allowedTypes` / `minEntities`）；沿用 `ValidationReport {ok, issues}`
- [ ] 逻辑层：`python/cad_service/validation.py` 实现 9 条规则码（`read_failed`、`empty_drawing`、`unsupported_entity`、`missing_layer`、`missing_required_layer`、`empty_required_layer`、`unclosed_polyline`、`missing_dimension`、`invalid_geometry`），issues 带规则码前缀与句柄/图层定位；`validate_dxf` 从磁盘回读，不复用内存文档；`SidecarClient.validateDxf`（120 秒超时）；`GenerationAgent` 的 `validate_drawing` 工具（路径由主进程注入）；主进程把校验报告写入 `historyStore.addGeneration`
- [ ] UI层：生成结果面板显示校验状态、问题条数与清单；历史生成卡片沿用现有 `校验通过 / 校验未通过（N）` 展示
- [ ] 测试：pytest 每条规则至少一个通过样例与一个拦截样例，断言规则码与定位信息；契约测试对落盘文件校验；GenerationAgent 单测；smoke 注入必填图层缺失 → 界面出现问题清单、历史显示未通过

## 验收标准
- 9 条规则均有可通过与可拦截样例，issue 文本以规则码开头并包含句柄或图层名
- 校验从磁盘回读：内存文档后续修改不影响已保存文件的校验结果（测试证明）
- 界面明确显示「校验通过」或「校验未通过（N）」及问题清单
- 生成记录的 `validation` 持久化，重启后历史页仍显示相同结果
- 校验不创建、不修改任何文件；校验失败时生成文件保留（重试在 021 处理）
