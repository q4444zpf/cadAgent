# 生成校验与失败重试

**Blocked by**: 011

**状态**: 通用校验规则与重试已由 020–021 取代；依赖 010 的图型规则集（标注完整性、关键几何闭合性等）见 024。本 ticket 保留作历史记录，不再单独实施。

## 目标
生成后自动回读 DXF 并执行规则校验（图层规范、实体完整性、标注完整性、关键几何闭合性）；失败时把问题清单反馈给 Agent 重试，超过上限终止并保留报告。

## 涉及层
- [ ] 数据层：校验报告结构
- [ ] 逻辑层：校验规则集、重试循环与上限、错误反馈
- [ ] UI层：校验结果面板、重试状态
- [ ] 测试：每条规则的正/负样例、重试与超限分支

## 验收标准
- 每条校验规则都有可通过与可拦截的样例
- 失败时 Agent 收到结构化错误并据此重试
- 超过重试上限后停止，保留有问题的文件与报告
- 校验通过后才提示生成成功
