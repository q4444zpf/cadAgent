# 模型配置与密钥管理

**Blocked by**: 001

## 目标
在设置页配置 Provider、模型与 API Key，保存到系统凭据库，能发起连接测试；提供假模型开关供离线开发与测试。

## 涉及层
- [x] 数据层：配置结构、密钥存取接口
- [x] 逻辑层：pi-ai Provider 装配、连接测试、假模型适配
- [x] UI层：设置页、测试连接按钮与结果反馈
- [x] 测试：配置持久化、连接失败分支、假模型固定响应

## 验收标准
- 修改配置后无需重启应用即可生效
- API Key 不出现在项目目录与日志中
- 连接测试能区分成功、鉴权失败、网络失败并显示原因
- 假模型模式下 Agent 可返回可预测的固定响应
