# 样例与首批图型确定

**Blocked by**: 无

## 目标
准备 2–3 张代表性 DWG，安装 ODA File Converter 转为 DXF 放入 `samples/`，据此确定首批图型与参数体系，形成后续生成任务的输入。

## 涉及层
- [ ] 数据层：`samples/` 下的转换后 DXF 与转换记录
- [ ] 逻辑层：无代码改动
- [ ] UI层：无
- [ ] 测试：转换后的 DXF 能被 003 的导入解析器正常解析

## 验收标准
- `samples/` 中存在 2–3 张转换后的 DXF，且均可被应用打开
- 首批图型以书面形式确认并补充进规格说明
- 记录 DWG→DXF 转换中的丢失项与保真检查结果
- 转换入口覆盖两条路径：已安装转换器时一键转换；未安装时给出「在自有 CAD 中另存为 DXF」的明确引导（兜底不依赖任何安装）

## 环境记录（2026-11-11）

- ODA File Converter **27.10**（Windows x64）已下载并静默安装至 `C:\Program Files\ODA\ODAFileConverter 27.10.0\ODAFileConverter.exe`；MSI 数字签名有效（Open Design Alliance / DigiCert）。
- CLI 已验证往返：`simple.dxf` → DWG（ACAD2018）→ DXF，ezdxf 回读实体数 4、类型分布（2 LINE + 1 CIRCLE + 1 TEXT）、图层集合、文字内容均与原图一致，版本升至 AC1032。
- 调用要点：参数依次为 输入目录、输出目录、输出版本、输出类型、递归、审计、输入过滤；进程为 GUI 子系统，必须显式等待退出；**不支持并发调用**（第二个实例会静默退出且不产出文件）。
- 仍缺：真实 DWG 样图与首批图型书面确认。
